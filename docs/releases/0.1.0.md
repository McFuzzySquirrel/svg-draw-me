# Project 0.1.0

**Release date:** 2026-10-08

## Summary

The first documented unreleased application baseline provides a browser-based, stroke-preserving SVG drawing workspace for standard and game-asset workflows.

## Highlights

- Responsive PixiJS workspace with mouse, touch, and pen/stylus input.
- Ordered stroke records with pressure, timing, pointer type, and style metadata.
- PNG/JPG tracing references and vector SVG reference imports.
- Standard SVG and editable SVG downloads.
- 25%–800% zoom, pointer-centered wheel zoom, two-finger pinch zoom, and panning.
- Pointer alignment and reference loading fixes.
- First-class shape tools and whole-object erasing.

## Compatibility and Prerequisites

- Node.js with npm for development.
- Modern browser with Pointer Events and WebGL or Canvas support.
- No backend, account, or database is required.

## Installation or Upgrade

```bash
npm install
npm run dev
```

For validation:

```bash
npm test
npm run build
```

## Known Limitations

- Work is held in browser memory until downloaded.
- There is no project save/reopen file workflow.
- Raster references are not automatically vectorized.
- Advanced SVG filters, masks, CSS, and external references may not preview fully.
- Layer visibility, opacity, positioning, and deletion controls are not yet exposed as a full layer editor.
- The eraser removes whole objects; partial stroke/segment erasing is not implemented.

## Validation

The release baseline was validated with the repository's automated tests and production build:

- `npm test` — 7 tests passing.
- `npm run build` — successful TypeScript check and Vite production build.

Manual browser smoke testing remains important for device-specific pointer, pinch, file, and download behavior.

## Security and Privacy

The app has no authentication or server upload path. Imported files are processed locally in the browser. Users should treat imported SVG markup and downloaded files as untrusted content when sharing outside their own workflow.
